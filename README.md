# soulful-bakes-agent

AI agent for Soulful Bakes customer inquiries and order assistance.

## Overview

Soulful Bakes Agent is an AI-powered assistant designed to help customers get accurate information about Soulful Bakes products and initiate an order.

The project is also a hands-on exploration of AI agent design, including instructions, knowledge grounding, tools, guardrails, testing, and human-in-the-loop workflows.
